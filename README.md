# Manajemen-Stok-Barang--CLI-
Ini merupakan program yang dimana berguna untuk memanajemen atau mengatur stok persediaan dan harga barang lewat CLI atau Terminal atau CMD.


## Cloning repositori ini
1. Jalankan ini di terminal atau CMD.

```
bash

git clone https://github.com/zgene2512-stack/Manajemen-Stok-Barang-CLI.git
```
2. Pastikan perintah di atas telah masuk ke dalam tempat untuk menyimpan file scriptnya.


## Setelah itu. Ikuti langkah yang ada di bawah ini:
1. Membuat Folder tempat skripnya berjalan nanti.
2. Masuk ke dalam folder yang dibuat.
3. Install paket JSON nya dengan cara buka terminal lalu ketik.

```
Bash

npm init -y
```
4. Install paket readline supaya bisa menginput di dalam terminalnya.
```
Bash

npm install readline-sync
```
5. Lalu jalankan menggunakan Node
```
Bash

node index.js
```
